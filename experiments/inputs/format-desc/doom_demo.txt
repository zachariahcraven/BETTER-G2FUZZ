Doom demo lump (.lmp, Doom v1.9 / Doom II demo format) for the game Freedoom: Phase 2 (a Doom II-compatible game with maps MAP01-MAP32). A demo is a recording of the players' inputs, replayed by the game engine. Layout: a 13-byte header (byte 0 version = 109, byte 1 skill 0-4, byte 2 episode = 1, byte 3 map number 1-32, byte 4 deathmatch 0-2, byte 5 respawn monsters 0/1, byte 6 fast monsters 0/1, byte 7 no monsters 0/1, byte 8 console player 0-3, bytes 9-12 player 1-4 present 0/1), then one 4-byte command per present player for every game tic (35 tics per second): forward move (signed byte), side move (signed byte), turn (unsigned byte, the high byte of the angle change), buttons (bit 0 fire, bit 1 use, bits 3-5 weapon number with bit 2 set to change weapon); the file ends with the byte 0x80
